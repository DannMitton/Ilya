## Where the memo and the code differ

- The memo cites the carry at `reader.py:2016-2027`; in this tree it is at `reader.py:2015-2025`. The code is what the table cites.
- The memo's table says the envelope "carries metre, key, clef, voice staff" (memo line 138). The code agrees it carries them, and adds what the memo leaves out: only metre and grouping are read from ink; key, clef, octave change, and voice staff ride as config pass-through cells (`reader/envelope.py:48-61`, the sentence at `:50`). So a key check over homr's output comes from `clefkey.py`, not from the envelope.
- No other disagreement was found at the lines opened.
