# Note: how the loupe and the one surface join the shipped desktop drawer

Written by Claude Design, 2026-08-25, r2, superseding r1. Companion to
`design-mobile-correction_r2_2026-08-25.html`. Commissioned by the brief's
deliverable clause: one schematic plus a note, so that done work is not
redesigned.

r1 of this note argued from r1 of the schematic, where the phone showed a window
onto the page at readable zoom. Dann's ruling of 2026-08-25 replaced that: the
phone shows the whole page at thumbnail scale, at full engraving resolution, and
the loupe supplies the readable zoom. That change makes the desktop argument
shorter, not longer, and this revision is mostly deletion.

Nothing here asks for a desktop redesign. The shipped drawer keeps its anchors,
its station order, and its width.

## Why the desktop case got easier

Desktop already shows the page whole. r2 makes the phone do the same thing at a
smaller size. So the page's role is now identical on both modalities, and only
one object has to travel across: the loupe.

Under r1 the note had to explain two differences, a cropped page and a new
magnifier. Under r2 there is one.

## What arrives on desktop

1. **The loupe.** Ruling 3 makes the loupe persist on desktop. It is the same
   object doing the same job: the taken measure, magnified in place, floating
   clear of the page, holding the insertion bar and the pitch crossbar. Desktop
   gains nothing new to learn, because the loupe is Finale's Speedy editing frame
   and the page behind it is the page that was already there.
2. **The page's two states.** While the loupe is up, the page stops taking clicks
   and drops one step of ink. This matters more on desktop than on the phone,
   because a desktop page is large enough that a stray click lands on it easily.
3. **The insertion bar as the selection.** Today the drawer names a selected note
   in words: `Selected: F3`. The bar states the same fact at the place the fact is
   about. The words stay, because the readout still names the entry.
4. **The named Undo.** The pill reads the same sentence on both modalities.
5. **One distinction, drawn everywhere.** A verb sits in a box. A navigation mark
   is bare: stepper arrows, the dismissal chevron, the tuplet triangles. Desktop
   should adopt this, because the drawer today boxes everything and so says
   nothing.

## What changes on desktop

The drawer's `CORRECT THE READ` station is re-cut into the four stations the
phone uses, in the phone's order: DURATION, PITCH, ACCIDENTAL and ENTRY, LYRIC.
Durations lead, because N.95 measured durations as the broken channel and pitch
as nearly fine.

This is a re-cut, not new function, with two exceptions that the phone forces and
desktop inherits for consistency:

- **Tuplets.** One row, disclosed in place inside DURATION: the Tuplet
  Definition's rhythmic sentence, each count driven by a stacked triangle pair on
  its left, each duration stepping on tap. The quick count row drawn in r2 is
  struck, so desktop never sees it.
- **The lyric verbs.** Named for what they touch, on the same surface as the note
  verbs rather than in a separate place.

The semitone verbs stay retired, per the slice 2 ruling of 2026-08-24.

## Why landscape is the bridge

The phone's landscape state is a narrow desktop drawer. Read them side by side:

| | desktop drawer | phone, landscape | phone, portrait |
|---|---|---|---|
| page | whole, un-displaced | whole, un-displaced | whole, un-displaced |
| anchor | left edge | left edge | bottom edge |
| stations | four, in order | four, same order | four, same order |
| verb strings | the shipped set | identical | identical |
| pull | one bare chevron, points the way it moves | identical | identical |
| loupe | floating, in place | identical | identical |

Only the anchor moves, and it moves once, on rotation. That is principle 7 doing
its job: geometry answers modality, not width. A singer who learns the desktop
drawer has learned the landscape dock exactly, and has one fact left to learn in
portrait, which is that the dock is at the bottom because the thumbs are.

## The one term-and-control question this note raises

The phone's surface is a **sibling dock**, not the drawer. On desktop the same
controls live **inside** the drawer. So the same four stations appear in two
containers with two names.

The resolution proposed is that the container names stay distinct and the
stations do not. `Drawer` names the object that holds every station on desktop.
`Dock` names the object that holds the four correction stations on the phone.
Both use one pull grammar, and a station is a station in both. That keeps
principle 3 on the stations, which are what the singer acts on, and spends the
one-term-per-concept budget on the containers, which the singer only ever opens
and closes.

If you would rather have one word, the word should be `drawer` in both places,
and the phone's bottom-anchored drawer becomes the ruled portrait form of the
same object. That reading costs the E.36 §1.4 anchors, which is why the schematic
does not assume it.

## What is not established

- Whether the desktop drawer's current width holds the four stations at their
  phone widths without wrapping. The measurement in the record is 520 of 932 px
  on the phone alias, and no desktop drawer width is recorded in the files read
  for this note.
- Whether the loupe's magnification should differ on desktop, where the page is
  already larger. 2.4 times is a portrait figure and no source establishes a
  desktop one.
- Whether desktop users want the loupe at all when the page is whole and legible.
  Ruling 3 says the loupe persists, and no measurement tests whether it earns its
  place there. r2 weakens this doubt rather than settling it: if the phone's whole
  page is legible enough to pick a measure from, the desktop page certainly is,
  which makes the loupe an editing instrument on both rather than a reading aid on
  either.
- The notation face. Every notehead and duration glyph in the schematic is a
  geometry stand-in. The operational spec names three type voices and none of them
  is notation, so the face that carries most of this interface is unnamed in the
  slate on both modalities.

## Coined and adopted in this note

Nothing is coined here. `Loupe`, `stepper`, `readout`, `station`, and `dock` are
adopted from the desk and from the Calm Authority slate. `Held measure` and
`measure tag` are coined in the r2 schematic and used here unchanged.
