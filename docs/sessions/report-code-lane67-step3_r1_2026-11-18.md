No spread, no outlier removal, no retake list. The report's `bucket` is `'middle'` then, and each such value's step is `'scale'`. **Removed, with their tests**: `fitWithoutOutliers`, `fitResonance`, the `Fit` type, `OFF_SHAPE_SEMITONES`, `spansArc`, `StandInReport.retake`, and the steps `'shift'` and `'shift-and-spread'` (`StandInStep` is `'template' | 'scale' | 'derived'`). Tested for a soprano.
3. **The four derived vowels keep `deriveFrom`** (`derivations.ts`, untouched). An anchor that is a scaled core vowel makes a value whose source stays `'surrogate'` (tested: [u] missing, [ɨ] is a surrogate).
