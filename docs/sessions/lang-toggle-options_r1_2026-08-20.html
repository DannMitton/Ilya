The honest difference in cost. Raised is one declaration and it will keep working if you ever add a fifth destination or change a band's hue. Sunk is four values that must be re-derived by hand the moment any band moves, which is the same class of thing the census already flagged when it found three hand-picked literals sitting beside one real token in this exact control.

And the difference in the eye. Raised puts the only light-on-dark relationship in the header into the one element that is a control, which is arguably correct: the sigil is a name and the pill is a door. Sunk keeps the header one continuous field of colour with the control pressed into it, which is quieter and closer to what you have now.
