What each stave space looks like in the loupe

N.138. Every size below is drawn at true CSS pixel size, so open this at 100% browser zoom and do not pinch. The stave spaces are the measured values from memo-n138-loupe-meter_r1_2026-09-14.md §2. The two type sizes are computed from them by the renderer's own constants: the page draws at lineGap: 5.5 (engraving.ts:31), and the underlay is emitted at font-size="12.5" for the Cyrillic and font-size="12" for the IPA in those same page units (staff-renderer.ts:2697, :2702). So the type does not shrink in step with the stave: at every scale it stands at 2.27 stave spaces.

What is measured and what is not. Measured: the stave space, the Cyrillic size, and the IPA size. Approximate: the vertical gaps between stave and underlay, and the horizontal spacing of the notes. The clef is the renderer's own primitive bass-clef shape (staff-renderer.ts:1686-1687), not the SMuFL glyph, and the meter digits are set in the sans face rather than in Finale Maestro's timeSig glyphs, because this page cannot load the notation font reliably from disk. So judge the text here, which is exact. The notation is indicative.

The words are real, taken from Kabalevsky T05 m. 9 as the file itself spells them. The scales are Sunless 01's.
