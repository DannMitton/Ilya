### 1d. VocalLineEvent and what a grace note would need
`packages/score-parser/src/types.ts:477-532`. Fields: `id`, `type: 'note' | 'rest'`, `measureIndex`, `rhythmicPosition: { fraction }`, `duration: { base, dots, tuplet?, fraction }`, `pitch?`, `tied?`, `syllable?`, `fermata?`, `articulations?`, `slurs?: SlurEnd[]`. No `grace` field exists. `Duration.base` is `NoteBase` (`types.ts:~576-585`: '128th' to 'breve'); `Duration.fraction` is required.
A grace note would need at least: a flag (for example `grace?: { slash?: boolean; steal?: ... }`), a `duration.fraction` of zero for bar sums (or an explicit exclusion), `duration.base` from `<type>` (generator emits `<type>` and no `<duration>` for grace, see item 6), a pitch, a rhythmicPosition equal to the principal note's, and its slur ends. Also decide: whether `pitch` belongs to the grace note's own alter state (accidentals; see item 2).
- `types.ts` is 999 lines. `scripts/ratchets.json` gives no ceiling for it, so the 1000-line limit for unlisted files applies (`newFileMaxLines`, ratchets.json line 3): ONE line of headroom. Any type addition must go in a new file or the limit must be raised on purpose.

## 9. Finale's grace-note editing (MakeMusic's own manuals)
Sources read (Finale user manuals at usermanuals.finalemusic.com):

All paraphrased; nothing quoted beyond a few words.
How it is done:
- ENTER, Simple Entry (mouse): choose the Simple Entry tool, pick the Grace Note Tool and a duration in the palette, then click where it goes; double-clicking the Grace Note Tool and clicking an existing note converts that note.
- ENTER, Simple Entry (keyboard): enter an ordinary note (it stays selected after entry; Ctrl+click selects an existing one) and press Alt+G to make it a grace note. Alt+G again adds a slash; one more press returns it to a regular note. Ctrl+G picks the Grace Note Tool, then notes are entered as usual, and Ctrl+G again deselects the tool.
- ENTER, Speedy Entry: enter the notes as ordinary notes first, select the Speedy Entry tool, click the measure (an editing frame appears), move the cursor onto the note with the arrow keys, and press ; (semicolon) or G. Repeating the same steps turns it back into a normal note. Several in a row form a run. The grave accent key slashes a flagged grace note (after turning off "Always Slash Flagged Grace Notes" in Document Options); the / key on the second note of a pair beams them.
- REMOVE: the grace-note pages say nothing about deleting. What the pages do say is a toggle back to a regular note (Alt+G, or ; or G), which keeps the note. From the shortcuts page (first section read only): Delete or Shift+Backspace deletes a note, Up/Down Arrow moves the pitch by a step, Shift+Up/Down by an octave. The page's section heading that those three belong to was reported by the summariser as "Simple Entry (the page's name for Speedy Entry)"; whether they are Speedy Entry keys or Simple Entry keys is NOT ESTABLISHED from my read, and the grace pages do not say they apply to grace notes.
- RE-PITCH: not described on the grace pages. By the same caveat, the general note keys above are the only documented pitch keys.
- Shortcut table entry: Alt+G toggles grace-note status in the Simple Entry section (Modify: Grace Note).
- Graphic (non-playing) grace-note symbols exist as Maestro symbols (the summary reported #201 slashed stem-up, #59 unslashed stem-up, #58 stem-down); not needed for N.187.
Design relevance (labelled as inference, not a finding): Finale treats a grace note as an ordinary note carrying a flag that is toggled, so add, remove and re-pitch are the ordinary note verbs plus one toggle; this matches how `toggleRest` and `NoteCorrection.type` already work in the Loupe.
