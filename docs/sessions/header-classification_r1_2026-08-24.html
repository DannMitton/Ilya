One scheme: the header classifies, the footer identifies

The division of labour: the header answers "what is this document, whose is it, and when" (the piece, the people, the voice, the date). The footer, option C on every page, answers "what made it and where to find it" (app, version, author, URL, licence, sources). Nothing is stated twice. Dashed amber marks what is new; everything else already ships. Names shown are placeholder content.
