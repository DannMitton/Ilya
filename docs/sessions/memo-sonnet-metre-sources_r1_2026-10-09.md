# Metre sources survey, r1, 2026-10-09

Read-only survey by a Sonnet research helper. Nothing in the user folders was changed. Time signatures below come only from files converted by the repository's denigma converter (global measure list). No page was rendered, viewed or OCR'd.

## Summary

- .musx files found (home folder, excluding Library, dot-folders, node_modules, Downloads): 114 (97 in Documents/Finale Files including its Backups folder, 17 in Documents/DMA Archive). Many are backups or copies; see the duplicates note below.
- .musx read successfully: 109. Failed: 5 (denigma WASM aborted): Bach BWV 1007 Cello Suite in G; Kabalevsky T04 (DMA Archive copy, though the Finale Files copy of T04 converted); and three Donizetti "Il mio ben m'abbandonò" backups (the only Donizetti .musx files).
- .mus (old binary) files in Documents/Finale Files: 340, listed by name only at the end.
- Score PDFs/scans considered: 4,754 PDF/image files outside Library, Downloads, dot-folders, Pictures, Facebook export and photo library were listed; about 1,809 are PDFs, most of them articles and books. Only candidates matched by title to a .musx were examined with pdfinfo, pdfimages and pdffonts.
- Pairs found: 22 pieces (the 10 Kabalevsky songs count separately). Of these, 13 have a true scan (image pages, no fonts); the others have only a vector PDF whose Creator field says Finale, so those PDFs are Finale exports and look like Finale output, not like a printed edition.
- Duplicates: many .musx files are backups or copies of the same piece (Backups folder, DMA Archive "F1 locations" copies). Tables use one .musx per piece and name the others only where they differ.
- The converter reports time signatures from the global measure list. It exposes only count and unit. It does NOT say whether a signature is printed as C or cut C, so C / cut C is NOT ESTABLISHED for every file.
- Matching is by title only. Whether the printed edition has the same bar numbers or the same time signatures as the Finale file was not checked (that would need looking at pages).

## Could not establish

- C and cut C: the converter output carries only count and unit, so no file says whether a 4/4 or 2/2 is printed as common time or cut time. For example Weill "Street Scene" 2/2 and Russian Alphabet Song 2/2 could be either.
- Five .musx failed to convert (WASM abort, no message): Bach BWV 1007 Cello Suite in G (no matching PDF found either); the DMA Archive copy of Kabalevsky T04; Donizetti "Il mio ben m'abbandonò" (three backups: plain, Fmaj, Fmaj Fclefs). The Donizetti scans exist (8-page scan "Donizetti - Sei arie no 5 - Il mio ben m'abbandonò.pdf", plus an 8-page Finale vector export), so this would be a pair if the file could be read. The .musx score.dat is not plain XML, so I did not try to decode it by hand.
- Wagner "Die Meistersinger von Nürnberg.musx" (3/4, 4/4) against "Wagner - Meistersinger - Pogners aria.pdf" (7-page scan): the titles differ in scope, so I did not pair them.
- Wagner Parsifal "pp48-65 Bist du's der diesen Schwan erlegte" (3/4, 4/4) and "Act 3 Gesegnet sei": no PDF found by title; the 28-page scan "Act 3 sc 1.pdf" may contain Gesegnet sei, which was not checked because that needs looking at pages.
- Sunless 02, 03, 05, 06 and the Sunless F1 files: no score PDF found (only the "Appendix A" analysis PDFs and page images inside the repository output folder, which are renders, not sources). A one-page "H Mitton_Musorgsky4.pdf" exists in MUS4241 (Musorgsky 4), not checked against Sunless 04.
- Copland Dickinson 05, Mahler Erntelied, Duparc Phydilé, Mozart Così recit, Weill Street Scene "Let things be", Beatles "Because", Pachecan Tabulation Values, Intro Jingle: no matching score PDF found by title (only 4/4, 2/2, 2/4, 3/4 anyway).
- Whether each printed edition has the same bar layout and signatures as its Finale file (for example the transposed Mendelssohn and Fauré files, or Vaughan Williams from a backup) was not checked.
- Time signatures that exist only on some staves, or that Finale stores as a "displayed" signature different from the performed one, are not visible in the global list the converter returns.
- Only 340 .mus names are listed; their contents cannot be read.
- I did not look in Downloads, Library, Pictures or any path containing "heldout", as instructed. Only the file listing of other folders was used.
