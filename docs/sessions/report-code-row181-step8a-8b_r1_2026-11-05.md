## 8a. The long dash is a joint again; `?extender=off` is the default

- **`?extender=`.** `extenderArm` (`omr/underlay-switch.ts`) returns `'off'` unless the address carries `?extender=a` or `?extender=b`. The default is `off`. `ExtenderArm` is `'off' | 'a' | 'b'` (`omr/underlay-extender.ts`).
  - `off`: `markExtenderNotes` still counts the tokens (so the console line keeps its `extenders (arm off): … underscore, … hyphen, … long-dash token(s)` counts) and marks no note. A real underscore token is not seated either (below), so no syllable is sustained and no `<extend>` is written.

- **`sustained` and the convention.** A long dash is seated as an extender only in a system that took the marks (8b): its unit's text becomes `_` just before `seatTokens`, so `sewWords` marks the syllable before it `sustained` and `writeLyrics` writes `<extend>`. An `extender`-kind seat in a system that did not take the marks is dropped from the seats, so a line not taken never sustains a syllable (the scan path and the typed path stay in agreement: `CONTRACT.md` §4).

## 8b. The extender marks are taken per system, only where they bring the counts to equal

- **The rule** (`omr/underlay-page.ts`, the `THE EXTENDER GATE` block after the slur gate). The marks are CANDIDATES, held apart from the notes. After the units exist, a system takes them only if (1) the arm is not `off`, (2) some note was marked, (3) the unmarked ties-only free count does not already equal the syllable units, (4) the slur reading does not already pass, and (5) the marks make the free notes and the units equal, either ties-only with the marks, or with the marks and the slur reading (the slur gate's own test: strict equality and at least one slur note still free). Otherwise the system is read as if nothing had been marked. This is the slur gate's rule (Dann 2026-10-20 03:37), applied after it.

With one note marked the branch had ties 15, slur 14, units 15: ties-only equals the units, but the slur reading, which was the right one, was lost. Under the gate that system is not marked: the slur reading already passes (4), so the marks are never tried.
