## How rows are counted

- A row is one control, or one set of controls that share a label and a purpose where noted.
- A radio group, a checkbox group, or a key stop list counts once per distinct label shown, as written in each row.
- Keyboard-only controls (shortcuts) and gestures (swipe, outside click) are listed as their own rows with kind `keyboard` or `gesture`. Delegated taps on the drawn score are listed as `tap target`.
- A button whose label swaps (for example Calibrate and Re-calibrate) is one row with both labels.
- The TOC links in Learn and Guide are one row each.
- Plain paragraphs that report status and carry no action are not controls (the drawer notices at `routes/+page.svelte:4280-4340`, orphan counts, storage lines, `binderError`, `binderNotice`).
- Label cells show EN, then FR. A label in brackets with `aria` is an aria-label, not visible text. Where the label is a literal in the component, the i18n key cell says `none`.
- Features behind the build wall `PUBLIC_INCLUDE_MARKUP_INSIGHTS` (`lib/wall.ts:9-10`) are marked in the "When it appears" cell. The value is `true` in `apps/web/.env` line 1 and blank in `.env.example`.
- NOT ESTABLISHED marks every place where the source did not let me say when a control appears.
