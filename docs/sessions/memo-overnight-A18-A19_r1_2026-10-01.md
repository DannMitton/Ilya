## A18. Structural intuitiveness for open-source contributors

**The question.** A capable newcomer opens the repository to build on Ilya. What stops them, and which five changes help most?

### What I found

**The front matter is in good shape.** `README.md` (111 lines) states what Ilya is, the "not AI" claim, how to run it, the four packages, and points to `ARCHITECTURE.md` (`README.md:62-80`). `CONTRIBUTING.md` (75 lines) names the scholarly boundary and what is not merged. `ARCHITECTURE.md` (222 lines, ratified 2026-09-28) is in matklad's shape with 13 invariants and a "Where to start" section (`ARCHITECTURE.md:205-213`). A newcomer reading these three knows where pronunciation rules, interface words, and analysis live.

**Codemap spot-check: 66 paths claimed, 65 exist, one is wrong.** I resolved every path `ARCHITECTURE.md` names against the tree. All resolve except `data/blurb-composer.json`, which the codemap places under `apps/web/src/lib/` by context (`ARCHITECTURE.md:84-86`, inside the `apps/web` bullet, and again at `ARCHITECTURE.md:173`). The file is at the repository root, `data/blurb-composer.json`, fetched at runtime as `/data/blurb-composer.json` (`apps/web/src/lib/loader.ts:64`). Ten further claims checked and true: `shane.profiles.v2` key (`apps/web/src/lib/voice/profileStore.ts:69`); `restoreSurface` (`destinations.ts:100`); `PUBLIC_INCLUDE_MARKUP_INSIGHTS` (`wall.ts:2-4`); `paginateScore` imported by MarkupPane (`markup/MarkupPane.svelte:64`); `InsightsIntake` mounted by the wizard (`voice/CalibrationWizard.svelte:48,1590`); `packages/phonology` entry `src/index.ts` exporting `GraysonEngine` (`packages/phonology/src/index.ts:19-26`); stress looked up in phonology, not dictionary (`packages/phonology/src/engine.ts:698`); `scripts/ratchets.json` ceilings exist with 16 files and a 1,000-line default (`scripts/ratchets.json:3-21`); `i18n.ts` exempt from the ceiling (`scripts/ratchets.json:5`); `e2e/` and `e2e-phone/` both present.

**What the codemap and README omit.** `tools/` holds 129 tracked files in three dated harnesses (`e16-harness`, `i-extractor-check`, `n168-frequency-run`) and appears in neither `README.md`'s structure block (`README.md:62-72`) nor `ARCHITECTURE.md`. `data/` at the root (the shipped dictionary and blurb data) is also absent from the README structure block. `.claude/launch.json` is tracked.
