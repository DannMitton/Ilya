# Learn: the always-hard consonants and Grayson's exceptions, draft r1

**Desk draft, 2026-09-26, for Dann to ratify, edit, or decline.** Learn says ⟨ж⟩,
⟨ш⟩, and ⟨ц⟩ "never palatalise", and Grayson names exceptions for each
(`OWED.md`, "The always-hard consonants depart from Grayson"). The draft keeps
the category name "always hard", which is Learn's term throughout (about thirty
places), and amends only the five places that say "never".

French drafted from Learn's own French. Words coined: none.
