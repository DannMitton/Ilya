Cost: the quietest of the three, and the least like a progress bar at a glance. Gains: no contrast risk at any position, no second copy of the string, and it reads as the pill filling rather than as a meter bolted to it.

Plate D

The indeterminate case, which is not optional

Loading dictionary…

When the server sends no content-length, fetchWithProgress reports -1 and there is no fraction to draw (loader.ts:286-292). The NDJSON merge path sets -1 too (loader.ts:639). This sweep is Kimi's own keyframes, already in the tree (AnalysisStation.svelte:194-202), shown here on Plate C's hairline.

Whichever of A, B, or C you rule, this one ships with it. A bar that cannot admit it does not know is a mark that says Ilya is unsure, which CONTRACT §6 forbids.

What the tree already has, read this session

  • The number is real. loaderState.progress is 0 to 1 from byte counting when content-length is present, and -1 when it is not. loader.ts:91-92, :273-295.
  • The bar is already built. A determinate sage fill on a stone track, with the indeterminate fallback, is drawn today inside the Analysis station's empty console. AnalysisStation.svelte:87-99 and :165-202, marked "Kimi spec". Analysis is closed by default now, so nobody sees it.
  • The string exists in both languages. input.transcribeLoading, "Loading dictionary…" and « Chargement du dictionnaire… », i18n.ts:171. No French is owed by any plate above.
  • The sage is the pill's own finish colour. --sage #8B9A7D, app.css:33; .btn-primary is background: var(--sage) with white text, IntakePanel.svelte:1176-1179. So a sage fill is the button filling in with what it is about to become.
  • A warm cache finishes instantly. On a cache hit progress is set to 1 without ever passing through the middle (loader.ts:704, :712), so on most of your reloads the bar would flash rather than travel. A short delay before it appears, DESK DEFAULT 200 ms, keeps a fast load silent.
