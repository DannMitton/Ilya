## Starting from what you have

*Deck line:* Where to begin, depending on what is in your hands.

Everything goes into the same place: the Input field in the drawer. Ilya works out what you gave it.

### A PDF of the score

Drop the PDF on the Input field, or select **choose a file**. The first time in a session, the reader takes about a minute to start. Ilya asks you to confirm the clef and the key signature, then reads every page. A picture of a score carries no words Ilya can read, so paste the poem into the same field afterwards. Then check the notes on **Markup**. "A walkthrough" follows this case from start to finish.

### A photograph of a page

Drop the photograph on the Input field. On a phone or tablet, the camera button beside the field takes it for you. From there, it is the same as a PDF. Ilya cannot read an iPhone photograph saved in HEIC format, and says so.

### A score file

Ilya reads MusicXML (`.musicxml`, `.xml`, `.mxl`), MNX, and Finale (`.musx`) files. A score file can carry its own words and title. When it does, and the poem box is empty, Ilya fills the box with the score's words, places them on the notes, and fills the Piece fields from the file's header, each tagged **from score**. Older Finale files (`.mus`, before 2014) cannot be read.

### Only the poem

Paste it into the Input field. "A walkthrough with only the poem" follows this case.

### A MIDI file

Ilya does not read MIDI files, and says so if you drop one.

### A new score for a song you already have

Drop it on the Input field. If Ilya already holds this music in another song, it asks whether to open that song or put the file in this one. If the new score is different music, and the syllables you placed would lose their notes, Ilya asks before it replaces anything, and offers to export the song first.
