Researched 2026-10-31. Method: WebSearch and WebFetch. Every value below was returned by a document opened in this task. Caveat on method: WebFetch passes each page through a summarizing model, so numbers are as that tool reported them from the document text. Bottom line: no source found gives sung-vowel fR1 values in Hz, tabulated by voice type, for countertenor, bass-baritone, tenor, mezzo-soprano, or contralto. The closest usable material is two Wolfe-group papers (Henrich et al. 2011; Henrich Bernardoni et al. 2014), detailed below.

## Terminology note

Henrich et al. use "R1" for the vocal tract resonance measured by impedance (acoustic injection at the lips), which is the same quantity as Bozeman's fR1. It is a direct measurement, not an inference from the spectrum. Studies using LPC or inverse filtering report "F1" (formant), which is an estimate from the radiated sound. I keep the labels as each source prints them.
